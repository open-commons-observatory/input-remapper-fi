# A Qt user interface instead of GTK

`request` · status `open` · 3 evidence items · [Back to the register](../register.md)

Issue #526 asks for the GTK interface to be ported to Qt. The 2021 guide (#177) lists it under possibly complicated work for contributors, and in July 2026 the maintainer, discussing tray-icon support (#1333), still talks about what would happen if a new Qt interface were ever written. He does not plan to build it himself; it needs a contributor with time.
